# MOSCHATO WEATHER — v1.0

Progressive Web App για πρόγνωση καιρού στο Μοσχάτο–Ταύρο.

## Πηγή δεδομένων
- NOAA GFS μέσω του Open-Meteo GFS API (`https://api.open-meteo.com/v1/gfs`).
- Συντεταγμένες κέντρου Μοσχάτου: 37.9536, 23.6789.
- Europe/Athens, °C, km/h, mm.
- Ωριαία πρόγνωση και ημερήσια πρόγνωση έως 16 ημέρες.

## Τοπική δοκιμή
Απαιτείται web server (το service worker δεν λειτουργεί σε `file://`).
```bash
python -m http.server 8000
```
Άνοιξε `http://localhost:8000`.

## Δημοσίευση
Ανέβασε όλα τα αρχεία του φακέλου σε HTTPS hosting (π.χ. Cloudflare Pages, Netlify ή δικό σου server). Μετά οι χρήστες μπορούν να επιλέξουν «Προσθήκη στην αρχική οθόνη».

## Σημαντικές εκκρεμότητες πριν από δημόσια παραγωγική χρήση
1. Επιβεβαίωση ακριβούς συντεταγμένης/grid cell με τον ιδιοκτήτη του σταθμού.
2. Έλεγχος και αναφορά των όρων Open-Meteo για δημόσια/εμπορική χρήση και προσθήκη attribution.
3. Ρύθμιση domain, HTTPS, analytics/privacy notice και ελέγχου σφαλμάτων.
4. Push notifications απαιτούν backend για αποθήκευση subscriptions και αποστολή ειδοποιήσεων· δεν ενεργοποιούνται μόνο με στατικό PWA.
5. Δεν υπάρχει ακόμη σύνδεση με τον τοπικό μετεωρολογικό σταθμό ή επίσημες προειδοποιήσεις Πολιτικής Προστασίας.
6. Η εφαρμογή παρουσιάζει πρόγνωση μοντέλου, όχι επιτόπιες μετρήσεις. Η αβεβαιότητα αυξάνει σε μεγαλύτερους προγνωστικούς ορίζοντες.
